# Voxel Frontier — 웹 복셀 샌드박스 v0.1

Minecraft Java 1.8.9의 일반적인 1인칭 블록 샌드박스 조작을 참고하되 **코드, 텍스처, 사운드, 상표는 복제하지 않고** 독립적으로 제작한 웹 게임의 초기 프로토타입입니다. 제공된 1.8.9 참고 파일은 분석에만 사용하고 이 저장소에 포함하지 않습니다.

## 실행

정적 파일 서버로 저장소 루트를 서비스합니다. 예: `python3 -m http.server 8000` 후 http://localhost:8000 접속. `file://` 직열기는 JavaScript 모듈 정책상 지원하지 않습니다. 첫 접속 시 Three.js 0.160.1이 jsDelivr CDN에서 로드되므로 인터넷이 필요합니다. WebGL과 마우스 포인터 고정을 지원하는 모바일은 터치·가상 스틱, 데스크톱은 마우스·키보드로 플레이합니다.

## 현재 조작

WASD 이동 / 마우스 시점 / Space 점프 / Shift 천천히 이동 / Ctrl 빠르게 이동 / 왼쪽 클릭 길게 파괴 / 오른쪽 클릭 설치 / 1~9 및 마우스 휠 단축 슬롯 / E 9칸 가방 / P 수동 저장 / Esc 일시 정지. 변경된 블록과 인벤토리, 플레이어 위치는 `localStorage`에 저장합니다.

## 스마트폰 및 자동 텍스처 (v0.3)

- 모바일 월드 화면을 손가락으로 밀어 시점을 회전하고, 이동 스틱/점프/설치/파괴 버튼을 이용합니다.
- **게임 안의 파일 선택 버튼은 없습니다.** 파일을 매번 누르지 않고, 게임 시작 때 `local-resources/manifest.json`을 탐색해 지원하는 블록 16개 텍스처 슬롯과 잔디 옆면 오버레이를 **자동으로** 적용합니다. 가방과 단축 슬롯 아이콘에도 같은 텍스처가 표시됩니다.
- 원본 Minecraft 텍스처·사운드는 저작권 자료입니다. 공개 GitHub 저장소와 배포 웹사이트에는 포함하지 않습니다. 로컬에서 소유한 JAR를 한 번 준비할 때 아래 명령으로 **개인용 게임 사본**에 설치할 수 있습니다 (이 폴더는 `.gitignore`로 제외):

```bash
python3 tools/prepare_local_resources.py "/path/to/1.8.9.jar"
python3 -m http.server 8000
```

`http://localhost:8000`에서 실행하면 별도 버튼 없이 모든 현재 블록 텍스처에 자동 적용됩니다. 준비 스크립트는 JAR의 `assets/minecraft/textures/` 아래에 있는 **전체 PNG**를 개인용 폴더로 추출해 추후 아이템·몬스터 구현을 위한 리소스도 보존하지만, 현재 렌더링하는 종류는 **블록 텍스처 16개 슬롯**뿐입니다. `1.8.json`은 소리·언어 에셋의 인덱스이므로 해당 PNG를 제공하지 않습니다.

공개 GitHub Pages 주소에서는 사용자 컴퓨터의 JAR를 읽을 권한이 없고 원본 파일도 저장소에 없으므로 **기본 독립 제작 텍스처가 나타납니다.** 과거 버전에서 한 번 등록하여 브라우저에 저장한 텍스처가 있을 때는 자동 복원됩니다. 공용 배포에서 원본 리소스를 자동 표시한다고 주장하지 않습니다.

## 구현 상황

구현 코드: 높이 기반 결정적 월드, 물과 나무, 13개 블록 ID(공기 포함 14개), 화면상 9칸 가방, 블록 노출면 메시, 픽셀 텍스처 코드 생성, 1인칭 키보드·마우스, 블록 충돌, 점프·중력, 파괴 및 설치, 느린 낮밤 변화, 로컬 저장.

**미구현**: Minecraft 1.8.9 지형 생성 알고리즘의 동일한 재현, 원본 에셋 배포, 바이옴/동굴/구조물의 완성, 도구/내구도, 2×2/3×3 제작, 방어구/배고픔/체력, 주민/몬스터/AI, 크리퍼 폭발/드롭 테이블, 레드스톤, 명령어, 차원, 서버 저장, 멀티플레이, 모바일 조작의 실기기 사용성 검증.

이 코드는 **첫 실행 버전**이며 1.8.9와 동등한 완성품이 아닙니다. 검증 기록은 [docs/STATUS.md](docs/STATUS.md)에 있습니다.

## v0.5 — 명령어 상세 안내 + 파티클 기반 (Java 1.8.9 바닐라 기준)

게임에서 `/` 키를 누르면 명령어 입력 패널이 열립니다. 모바일에서는 `명령어 /` 버튼을 사용합니다. 사용 중인 명령어에 따라 **필요한 인수 칸, 가능한 선택 값, 예제**가 표시됩니다. `Tab` 자동완성, `↑/↓` 제안 선택, `Enter` 실행, `Esc` 닫기를 지원합니다. 선택 목록을 손가락이나 마우스로 눌러 인수를 채울 수 있습니다.

**실제로 작동하는 부분 명령어:** `/help`, `/time set|add|query`, `/tp x y z`, `/setblock x y z block`, `/fill x1 y1 z1 x2 y2 z2 block`(최대 4096블록), `/gamerule doDaylightCycle`, `/particle flame|smoke|cloud|crit|reddust ...`, `/seed`. 상대좌표 `~` 사용 가능. 파괴·설치에 기본 입자가 연동됩니다.

**미구현:** 1.8.9 바닐라의 다른 명령어, 정식 엔티티·명령 블록, AI·생존, 전체 파티클 텍스처, NBT, 허용 치트/권한 설정, 원작과 같은 물리 및 그래픽. 세부 작업표는 [`docs/IMPLEMENTATION_PLAN.md`](docs/IMPLEMENTATION_PLAN.md) 참고.
