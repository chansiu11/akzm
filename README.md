# Voxel Frontier — 웹 복셀 샌드박스 v0.1

Minecraft Java 1.8.9의 일반적인 1인칭 블록 샌드박스 조작을 참고하되 **코드, 텍스처, 사운드, 상표는 복제하지 않고** 독립적으로 제작한 웹 게임의 초기 프로토타입입니다. 제공된 1.8.9 참고 파일은 분석에만 사용하고 이 저장소에 포함하지 않습니다.

## 실행

정적 파일 서버로 저장소 루트를 서비스합니다. 예: `python3 -m http.server 8000` 후 http://localhost:8000 접속. `file://` 직열기는 JavaScript 모듈 정책상 지원하지 않습니다. 첫 접속 시 Three.js 0.160.1이 jsDelivr CDN에서 로드되므로 인터넷이 필요합니다. WebGL과 마우스 포인터 고정을 지원하는 데스크톱 브라우저를 권장합니다.

## 현재 조작

WASD 이동 / 마우스 시점 / Space 점프 / Shift 천천히 이동 / Ctrl 빠르게 이동 / 왼쪽 클릭 길게 파괴 / 오른쪽 클릭 설치 / 1~9 및 마우스 휠 단축 슬롯 / E 9칸 가방 / P 수동 저장 / Esc 일시 정지. 변경된 블록과 인벤토리, 플레이어 위치는 `localStorage`에 저장합니다.

## 구현 상황

구현 코드: 높이 기반 결정적 월드, 물과 나무, 13개 블록 ID(공기 포함 14개), 화면상 9칸 가방, 블록 노출면 메시, 픽셀 텍스처 코드 생성, 1인칭 키보드·마우스, 블록 충돌, 점프·중력, 파괴 및 설치, 느린 낮밤 변화, 로컬 저장.

**미구현**: Minecraft 1.8.9 지형 생성 알고리즘의 동일한 재현, 원본 에셋 배포, 바이옴/동굴/구조물의 완성, 도구/내구도, 2×2/3×3 제작, 방어구/배고픔/체력, 주민/몬스터/AI, 크리퍼 폭발/드롭 테이블, 레드스톤, 명령어, 차원, 서버 저장, 멀티플레이, 모바일 터치 조작.

이 코드는 **첫 실행 버전**이며 1.8.9와 동등한 완성품이 아닙니다. 검증 기록은 [docs/STATUS.md](docs/STATUS.md)에 있습니다.

## 모바일·리소스팩(v0.2)
손가락으로 월드 화면을 드래그하면 시점을 회전합니다. 왼쪽 조이스틱으로 이동하고 오른쪽 점프/파괴/설치, 상단 가방/메뉴 버튼을 이용합니다. PC 키보드·마우스 조작도 유지합니다.
시작 화면의 '1.8.9.jar / 리소스팩 ZIP 불러오기'에서 **사용자 기기의 파일을 직접 선택**하면 블록 텍스처 16 슬롯과 잔디 오버레이를 로컬 브라우저에서 불러옵니다. 기기 브라우저에 합성 Atlas를 저장하며 서버로 파일을 전송하지 않습니다. `MC_1.8.9_Selected.zip`은 사운드/언어 객체 묶음이므로 블록 텍스처가 없습니다. `1.8.9.jar`를 선택하세요. 원본 텍스처/JAR는 저장소에 포함되지 않습니다. 전체 1.8.9의 모든 모델/아이템을 재현한 단계는 아닙니다. ZIP 압축 해제에 JSZip 3.10.1 CDN을 사용합니다.
