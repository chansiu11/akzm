# Voxel Frontier — 웹 복셀 샌드박스 v0.1

Minecraft Java 1.8.9의 일반적인 1인칭 블록 샌드박스 조작을 참고하되 **코드, 텍스처, 사운드, 상표는 복제하지 않고** 독립적으로 제작한 웹 게임의 초기 프로토타입입니다. 제공된 1.8.9 참고 파일은 분석에만 사용하고 이 저장소에 포함하지 않습니다.

## 실행

정적 파일 서버로 저장소 루트를 서비스합니다. 예: `python3 -m http.server 8000` 후 http://localhost:8000 접속. `file://` 직열기는 JavaScript 모듈 정책상 지원하지 않습니다. 첫 접속 시 Three.js 0.160.1이 jsDelivr CDN에서 로드되므로 인터넷이 필요합니다. WebGL과 마우스 포인터 고정을 지원하는 모바일은 터치·가상 스틱, 데스크톱은 마우스·키보드로 플레이합니다.

## 현재 조작

WASD 이동 / 마우스 시점 / Space 점프 / Shift 천천히 이동 / Ctrl 빠르게 이동 / 왼쪽 클릭 길게 파괴 / 오른쪽 클릭 설치 / 1~9 및 마우스 휠 단축 슬롯 / E 9칸 가방 / P 수동 저장 / Esc 일시 정지. 변경된 블록과 인벤토리, 플레이어 위치는 `localStorage`에 저장합니다.

## 스마트폰 및 로컬 리소스팩 (v0.2)

- 스마트폰에서는 **월드 화면에서 손가락 드래그**로 시점을 회전합니다. 왼쪽 이동 스틱, 오른쪽 점프/파괴/설치 버튼, 상단 가방/메뉴 버튼을 사용할 수 있습니다. 화면 입력은 스크롤이나 탭 선택과 충돌하지 않도록 분리했습니다. PC의 마우스 시점 및 키보드 이동은 유지됩니다.
- 게임의 시작 메뉴에서 **`1.8.9.jar / 리소스팩 ZIP 불러오기`**를 눌러 사용자의 원본 `1.8.9.jar`나 블록 PNG가 있는 리소스팩을 **자기 기기에서 선택**할 수 있습니다. 선택한 파일은 서버로 업로드되지 않습니다. 런타임에 JAR/ZIP을 열어 16종 기본 블록 텍스처와 잔디 측면 오버레이를 Atlas에 적용하고, 변환된 아틀라스를 **그 기기의 브라우저 저장공간에만 저장**합니다. 다른 기기/다른 브라우저에서는 다시 선택해야 합니다.
- `MC_1.8.9_Selected.zip`은 사운드/언어용 해시 에셋 묶음이며 블록 PNG가 없어서 **이 선택기로 적용할 수 없습니다**. `1.8.9.jar`를 선택하세요.
- 전체 Minecraft 모델/아이템/몬스터/사운드 리소스팩 지원은 아직 없고, 현재 구현된 블록 16개 텍스처 슬롯만 대응됩니다. 잔디/잎/물의 색은 기본 바이옴과 유사한 색을 내려는 런타임 틴트를 적용합니다. 원본 텍스처/JAR는 공개 저장소에 저장하지 않습니다.
- ZIP 해제에 `JSZip 3.10.1` CDN을 이용합니다. 최초 접속 시 인터넷 연결이 필요합니다.

## 구현 상황

구현 코드: 높이 기반 결정적 월드, 물과 나무, 13개 블록 ID(공기 포함 14개), 화면상 9칸 가방, 블록 노출면 메시, 픽셀 텍스처 코드 생성, 1인칭 키보드·마우스, 블록 충돌, 점프·중력, 파괴 및 설치, 느린 낮밤 변화, 로컬 저장.

**미구현**: Minecraft 1.8.9 지형 생성 알고리즘의 동일한 재현, 원본 에셋 배포, 바이옴/동굴/구조물의 완성, 도구/내구도, 2×2/3×3 제작, 방어구/배고픔/체력, 주민/몬스터/AI, 크리퍼 폭발/드롭 테이블, 레드스톤, 명령어, 차원, 서버 저장, 멀티플레이, 모바일 조작의 실기기 사용성 검증.

이 코드는 **첫 실행 버전**이며 1.8.9와 동등한 완성품이 아닙니다. 검증 기록은 [docs/STATUS.md](docs/STATUS.md)에 있습니다.

## 타이틀/메뉴 리메이크 (v0.4)

상용 게임의 메뉴 이미지·로고·폰트 또는 코드 자체를 복제하지 않은 **독립적인 블록 스타일 메뉴**를 추가했습니다. 메인 타이틀 → 싱글플레이 세계 선택 → 새로운 세계 생성/삭제, 실제 동작하는 설정(시야각·렌더 거리·시점 감도·좌표 표시), 일시정지 → 재개/저장 후 타이틀 이동, 도움말을 지원합니다. 세계별 블록 변경·인벤토리·위치 저장 키는 별도로 관리합니다. 현재 모든 새 세계가 같은 시험 지형 시드로 생성되는 한계가 있으며 실제 멀티플레이는 없습니다.

- PC 1365×768 및 모바일 390×844 크기의 Chromium에서 HTML/CSS 메뉴 화면 렌더링, 버튼 화면 전환, 시야각 저장을 검사했습니다.
- Node.js 자동 테스트와 JavaScript 구문 검사도 통과했습니다.
- 브라우저 테스트 환경에서 외부 Three.js CDN 접근이 차단되어 **완전한 3D 엔진과 실제 GPU 렌더링/이동은 이번 환경에서 통합 검증할 수 없었습니다.** 작동 완료로 기록하지 않습니다.
- 로컬에서 소유한 원본 JAR를 개인적으로 준비한 경우에만 텍스처를 시작 시 자동으로 읽습니다. 공개 GitHub Pages는 기본 독립 제작 텍스처를 자동 사용합니다. 원본 텍스처/사운드는 Git에 커밋하지 않습니다.
