## v0.5 명령어 관련 구현 제약

- 지원: `/help`, `/time`, `/tp` (자신의 좌표만), `/setblock`, `/fill` (최대 4096 블록), `/particle` (5가지 색 점 입자), `/gamerule doDaylightCycle`, `/seed`.
- 상대좌표 `~`와 기본 블록 이름(`minecraft:stone` 등)을 처리한다. 실제 구현되지 않은 블록·아이템·엔티티 및 명령은 오류를 반환한다.
- 명령어 권한, 마인크래프트 1.8.9 전체 NBT·데이터 값·대상선택자·명령블록·함수 호출·전체 파티클은 **미구현**이다.
- 본 패널은 **각 명령어의 인수 안내와 예문을 기존보다 확장한 독립 제작 UI**다. 원본 UI 텍스처를 복사한 것은 아니다.
- `fill`은 브라우저 프레임 급락 방지를 위해 제한되어 있다. `/tp`가 블록 안으로 이동하면 질식 판정이 없으므로 플레이어가 겹칠 수 있다.

## 각 단계 공통 품질 조건
1. 소스의 자바스크립트 구문을 검사한다.
2. 순수 로직은 Node.js 단위 테스트를 추가한다.
3. 브라우저 DOM·사용성은 가능한 범위에서 실측하고, Three.js/실기기 미검증은 명시한다.
4. GitHub에 반영할 때만 원격 `main` HEAD와 기존 기록을 확인한다. **이 코드 작성본은 어떤 원격에도 적용하지 않는다.**
5. 작업 단계별로 코드와 테스트, 상태 문서를 동기화하여 커밋한다.

- 원작과 다르다고 발견하더라도 즉시 고치지 말고 차이점과 근거부터 사용자에게 알림.

- 전 단계 종합 회귀/인게임/원작 차이 비교는 마지막에 수행.
