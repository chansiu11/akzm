## 단계별 검토 중 실제 발견하고 수정한 문제

1. 구름과 천체가 기존 카메라의 먼 평면 75블록 바깥에 나타나지 않을 수 있는 문제 → 카메라 먼 평면 300블록 및 별·구름 안개 처리로 수정. 월드 청크의 별도 렌더 거리 로직은 유지.
2. 밝기가 단순한 전역 광원에만 의존하는 문제 → 청크 메시 정점 컬러와 인접한 켜진 램프를 이용한 근사 음영 추가. 정식 블록광은 여전히 미완성.
3. 램프의 빛이 빛을 내는 블록 자체에 의해 가려지는 광선 검사 오류 → 발광체 블록은 자신의 광선을 가리지 않도록 수정 후 회귀 테스트.
4. 세계 생성 알고리즘 변경 시 저장된 제3세대 세계가 달라지는 문제 → generator=3 저장 세계와 generator=4 신규 세계 생성 경로를 분리.
5. 원작에 없는 시험 폐허 구조물 및 산악 밖 에메랄드 생성 → **새로운** 생성기에서만 변경.
6. 낙하 블록 틱의 처리량 제한에 걸리면 다음에 처리할 블록이 버려지거나 앞선 블록이 계속 우선 처리되는 문제 → 나머지 대기열 우선 순환으로 수정.
7. 제작대·곡괭이 업적을 선행 조건을 충족하기 전에 획득하거나, 이전 활동이 나중에 충족되지 않는 문제 → 선행 업적 언락 후 완료 조건 다시 평가.
8. 시험 서버 종료 후 블록 변경이 소실되는 문제 → 별도 JSON 저장·재시작 복원 추가. **실제 배포 서버는 설정하지 않음.**
