# 단계 3 코드와 검증 기록 — 2026-10-20

**범위:** 공식 Minecraft Java Edition 1.8.9 바닐라를 기능 기준으로 삼지만, 이 프로젝트는 독립 게임이며 해당 원본의 프로그래밍 코드와 에셋을 재배포하지 않음.

**적용 여부:** GitHub/Render 업로드하지 않은 로컬 코드 전용 버전 v0.7. 사용자의 이전 2단계 ZIP을 기반으로 새 복사본에만 작성.

## 개발한 코드

- `src/terrain.js`: Y=0..255, 해수면 63, 6가지 독자적인 환경 영역(바다/평원/숲/사막/산악/설원), 3차원 동굴, 석탄·철·금·다이아몬드·레드스톤·청금석·에메랄드 광석, 참나무/가문비나무, 희소한 작은 폐허, 서로 다른 세계 시드.
- `src/block-registry.js`, `src/atlas.js`, `src/resource-pack.js`, `src/auto-resources.js`: 신규 블록 ID 18..28의 정의/독립 제작 기본 텍스처와 원본 사용자가 준비한 리소스 경로. 기존 ID 0..17 유지.
- `src/menu.js`, `index.html`: 새 세계에 사용자 지정 시드 또는 자동 시드 저장. 이전 세계 목록/브라우저 저장 키 유지.
- `src/main.js`: 월드별 생성기·시드·시작 좌표 선택, 지형 높이에 따른 메시 구축, 바이옴·시드 디버그 표기.
- `src/chunk-builder.js`: 256 높이 청크의 CPU 면 메시 계산을 4열씩 프레임 분산. 변형된 청크는 빌드 완료 후 다시 큐에 삽입하며 기존 메시는 완성 후 교체.

## 원작과의 차이 — 확인 후 보류, 임의로 수정하지 않음

1. 자체 생성기로 원작 Java 1.8.9의 정확한 시드 지형과 **불일치**. 본 파일에는 원작의 바이옴/지형 생성 알고리즘이 구현되어 있지 않음.
2. 바이옴 6종의 독자적인 간소화 환경이므로 원작 모든 바이옴·기온·강수·지형 경계 규칙과 다름.
3. 동굴은 3D 노이즈 기반 작은 공간이며 원작의 터널·용암호수·협곡·지하 구조물 생성과 다름.
4. 광석은 자체 난수/깊이 분포를 사용하여 원작 광맥의 크기·빈도·분포와 다름.
5. 작은 폐허는 독립 제작 구조물로 원작 마을·사원·폐광·요새 등과 같지 않음.
6. 새 세계 숫자 시드는 32비트 정수로 정규화됨. 원작 Java 시드의 넓은 정수 범위를 재현하지 않음.
7. **기존 저장 세계는 호환성을 위해 구형 36 높이 지형을 유지**, 따라서 새 세계와 생성 범위가 다름.
8. 1단계 명령어의 `/seed` 응답은 여전히 고정 시드(`18909`)로 구현되어 있어, 새 세계의 실제 시드와 다를 수 있음. 사용자가 명령어 확장을 마지막에 진행하라고 했으므로 수정하지 않음.
9. 원작의 모든 블록/지형 레이어·동굴 구조·액체 흐름과 GPU 렌더링 동등성은 구현·검증되지 않음.

## 진행 중단 기준

사용자는 한 단계씩 **직접 인게임으로 테스트**하고 다르면 바로 바꾸지 말고 먼저 알려 달라고 요청함. 3단계는 자동검증만 통과했고 실제 인게임 접근이 차단됨. 따라서 **3단계를 최종 승인 또는 원작 동일 판정하지 않으며, 4단계 이후와 모든 명령어 Tab 확장은 시작하지 않음**. 배포/저장소 수정 금지 유지. 게임 실행이 가능한 환경에서 인게임 점검 결과와 원작 차이를 확인한 다음 단계 판단 필요.
