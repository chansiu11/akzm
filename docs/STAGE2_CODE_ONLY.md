## 포함 기능

1. `block-registry.js`: 기존 블록 ID를 유지하고 물성/레이어/모델/상태 등록.
2. `item-registry.js`: 블록 아이템과 독립 아이템(석탄) 구분, 9칸 인벤토리 검증.
3. `block-mesh.js`: 큐브, 반 블록, 계단의 부분 면 렌더링 메시 생성.
4. `terrain.js`: v1 저장 데이터 읽기, 블록 상태 포함 v2 저장 데이터 읽기/쓰기.
5. `main.js`: 렌더 레이어 분리(불투명/잎/유리/물), AABB 충돌, 반 블록/계단 0.6칸 자동 오르기, 4종 블록 설치/채굴과 건설용 블록 목록.
6. `atlas.js`, `resource-pack.js`, `auto-resources.js`: 19칸 텍스처 아틀라스 및 로컬 사용자 아틀라스 호환.
7. `test/stage2.test.js`: 블록 레지스트리 안정성, 상태 유효성, AABB, 구버전 세이브, 아이템, 메시, UV 테스트.

## 아직 없는 기능

- 전체 바닐라 블록, 회전하는 반 블록/계단 조합(코너 계단 등), 세밀한 조명, 레드스톤, 제작대 GUI와 제작법, 정식 드롭 테이블, 생존, AI, 멀티플레이 등.
- 명령어 추가 및 Tab 확장은 사용자의 지시에 따라 개발 계획의 **마지막 단계로 연기**합니다. 현재 명령어는 v0.5 기능을 그대로 둡니다.
- 기존 world save v1 호환은 테스트했으나 브라우저에서 오래 저장한 실제 사용자 세이브의 모든 사례와 3D GPU 완전 테스트는 아직 검증하지 못했습니다.

## 실행/검증

```bash
cd akzm-stage2-code-only
npm test
python3 -m http.server 8000
```

브라우저에서 http://localhost:8000 에 접속하세요. Three.js는 외부 CDN 접속이 필요합니다. 게임 실행까지 확인하려면 별도로 GPU/WebGL 테스트를 진행해야 합니다. `file://` 직접 열기는 지원하지 않습니다.
