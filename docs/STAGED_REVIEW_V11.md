# v1.1 단계별 원작 1.8.9 차이 수정 및 회귀 테스트 (로컬 개발본)

비교 대상: Minecraft **Java Edition 1.8.9 바닐라**. 비교 대상 코드: v1.0 로컬 ZIP에서 별도 추출한 v1.1. 기존 v1.0 파일, GitHub `chansiu11/akzm`, Render 서비스 모두 변경하지 않음.

## 수행한 단계

### A. 생존·음식·사망·호흡
- `food.js`의 독립 데이터로 사과·빵의 허기/포만도, 1.6초 사용 시간을 정의. PC 우클릭 또는 모바일 설치 버튼을 길게 눌러 섭취. 상자 등 상호작용 블록을 먼저 열 수 있도록 입력 우선순위 조정.
- 일반 참나무형 잎에서 매우 낮은 확률로 사과를 획득할 수 있게 연결. 빵 획득·제작은 아직 별도 작업 필요.
- 생존 세계에서 사망할 경우 인벤토리/오버플로 목록을 드롭 엔티티로 넘기고 슬롯 초기화. 엔티티 용량 부족 시 아이템을 버리지 않고 잔여 보관. `keepInventory` 게임 규칙·경험치·침대 부활 규칙은 미구현.
- 플레이어 발 대신 눈높이(약 1.62블록)로 잠수 시 호흡 판정. 수면 위로 나올 때 공기량 복원.
- 자연 회복·굶주림 타이머가 충족 조건 바깥에서 누적되지 않도록 수정.
- 이동 실제 거리(걷기·달리기·수영)와 점프·채굴·타격에 따른 소모도를 계산. 원작의 모든 상태 효과, 난이도 및 질주 가속도까지 재현한 것은 아님.

### B. 화로·아이템 엔티티·장비 데이터
- 화로의 연소 중인 연료는 재료가 없거나 출력이 막혀도 계속 소모되도록 수정; 입력이 없으면 새 연료를 점화하지 않음. 큰 `dt`에서도 남은 연료를 초과해 제련하지 않도록 구간별 진행.
- 바닥 아이템은 플레이어의 인벤토리가 가득 차 있더라도 수명 300초가 되면 소멸하도록 조건 순서를 수정.
- 바닥에 떨어지는 도구, 저장된 드롭, 상자 입출금·상자 파괴 드롭에 도구 내구도(`damage`) 보존. 중첩 불가능한 장비가 같은 상자 슬롯에 누적되지 않도록 검증.
- 사과·빵의 GUI 아이콘용 **독립 제작 절차적 이미지**를 추가. 로컬 원본 아이템 PNG가 사용자 기기에 준비된 경우 해당 두 이미지도 자동 로딩할 수 있도록 확장. 원본 저작권 에셋은 배포하지 않음.

### C. 엔티티·전투·렌더 자원
- 기본 근접 공격 테스트 거리 4.5에서 3블록로 감소. 블록 시야 판정 유지, 약 0.5초의 피격 중복 방지 시간 추가.
- 55블록 떨어진 생물을 즉시 삭제하는 대신 휴면 목록으로 보관하고 근처에 돌아오면 재생성. 저장 과정에 휴면 목록을 포함.
- 엔티티 몸체·머리 렌더링에 공유 기하 구조를 사용해 반복 스폰 시 GPU 버퍼 생성·제거를 줄임.
- 생물별 AI, 자연 스폰·디스폰, 공격 판정, 모델은 **시험용 단순 모델**이며 원작 1.8.9와 일치하지 않음. 휴면 목록에 매우 많은 생물이 들어간 경우 정식 월드 데이터 저장과 동일한 확장성을 보장하지 않음.

### D. 블록 갱신·기존 명령어와 연결된 데이터 청소
- 이미 지원 중이던 `/setblock`·`/fill` 동작이 상자/화로를 바꿀 경우 낡은 블록 엔티티 내용을 월드 상태에서 제거. 새로운 명령어를 추가한 것은 아님.
- 레버를 같은 블록 ID로 재설치하며 켜짐 상태가 꺼지는 경우에도 인접 램프를 재계산하도록 수정.
- 전체 레드스톤 신호·전파·블록 업데이트는 구현하지 않았음.

## 검증 기록

- 시작 단계 v1.0: 자동 테스트 **91건 통과**.
- v1.1 그룹별 새 자동 테스트: 음식 섭취, 사망 시 아이템 이전, 내구도 보존, 화로 연소, 바닥 아이템 300초 수명, 근접 거리, 피격 간격, 시야 차단, 블록 엔티티 청소, 레버 재설치, 회복·굶주림 시간, 이동 거리 소모도 등.
- 최종 `npm test`: **111건 통과, 0건 실패**.
- `node --check` 소스·테스트·서버 JavaScript 구문 검사 및 JS 상대 import 연결 검사 통과.
- 정적 HTML DOM ID 검사: `src/main.js`, `src/menu.js`, `src/command-ui.js`의 참조 누락 **0건**.
- Chromium으로 `127.0.0.1` 브라우저 방문 시 `net::ERR_BLOCKED_BY_ADMINISTRATOR` 재현. 실제 GPU·3D 월드 입력·모바일 실기 플레이 **미검증**.

## 수정 범위 밖으로 남은 원작 차이

- 원작의 전체 블록·아이템·모델·조명·액체·파티클·상호작용 UI·제작법, 지역·시드·광물·구조물·차원 생성, 엔티티 모델과 AI, 완전한 멀티플레이는 아직 원작과 다름.
- 원작의 64비트 시드 및 동일 시드의 동일 월드 재현 불가. 독립적인 자체 노이즈 월드 생성기를 그대로 사용.
- 정식 체력·허기 난이도/상태 효과/장비/크리에이티브·관전 등 부족.
- 명령어 8개 부분 구현 상태 그대로. **전체 1.8.9 명령어 및 인수별 Tab 자동완성은 사용자 요청대로 마지막 단계로 보류.** `/seed` 고정값 문제도 미수정.
- 이번 테스트는 **코드 회귀 검증**에 해당. 실제 Java 1.8.9 바닐라와 나란히 인게임 플레이 및 픽셀·움직임 일치 검증은 실시하지 못함.
- 따라서 어느 단계도 **원작과 100% 동일하거나 완벽하게 완료됐다고 판정하지 않음**. 신규 코드 작성과 테스트된 수정 범위만 기록함.

## 앞으로의 합리적 구현 순서

1. 생존 난이도·상태 효과·장비·먹이·죽음 세부 조건.
2. 액체·블록 틱·화로의 전체 제련 재료와 연료·레드스톤 전파.
3. 아이템·블록 전체 모델 및 GUI·상호작용·애니메이션.
4. 월드 시드·바이옴·구조물·차원과 원작 자료에 맞춘 비교 테스트.
5. 동물·몬스터 개별 AI·엔티티 물리·스폰 및 지속성.
6. 그래픽 조명·물·파티클·사운드, 멀티플레이·저장 최적화.
7. Java 1.8.9 전용 명령어 전체·인수 자동완성.
8. 실제 브라우저 3D 월드와 Java 1.8.9 바닐라를 동일 상황에서 플레이하며 차이 재검증.
