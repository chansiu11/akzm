# v1.7 Java Edition 1.8.9 바닐라 화면 비교 및 검증

## 기준과 범위
- 공식 Java Edition 1.8.9 바닐라의 기본 GUI 구성과 논리 픽셀 크기를 참고한다.
- Mojang의 로고, 1.8.9 JAR 내 이미지/소리, GUI 원본 파일은 저장소에 포함하지 않는다.
- 1:1 픽셀 차이 검증을 하려면 원작/웹게임 **동일 해상도, FOV, GUI 배율, 리소스팩, 카메라/시드/시간/날씨/플레이어 위치**의 대응 스크린샷이 필요하다.

## 테스트
- `npm test`: 163/163 통과
- `node --check src/main.js`: 통과
- Chromium `page.set_content` DOM/CSS 픽셀 배치 검사: 1280×720, 800×600, 390×844 통과
- 독립 UI 화면 `docs/MENU_*`, `docs/HUD_*`, `docs/INVENTORY_1280x720.png` 생성
- **실제 게임 주소를 Chromium으로 탐색하면 `net::ERR_BLOCKED_BY_ADMINISTRATOR` 반환**, 클라이언트 Three.js CDN 접근도 불가. 따라서 WebGL 인게임, 블록의 실제 시각, FPS·터치 실기기 테스트는 미수행.

## 여전히 같지 않은 부분
- 공식 텍스처, 로고, GUI 스프라이트, 마인크래프트 글꼴은 사용하지 않으며 의도적으로 독립 이미지로 대체.
- 블록별 3D 모델·잔디·액체·하늘 광·그림자·구름/파노라마가 원작 픽셀별로 같지 않음.
- 원작의 전체 인벤토리 창 구조(장비 슬롯·캐릭터 미리보기·제작/화로의 전용 GUI) 미구현.
- 자작 모바일 조작은 Java 1.8.9 원작에 없는 별도 접근성 UI.
- 실제 1.8.9 클라이언트를 같은 조건에서 구동하여 픽셀 diff를 계산한 테스트는 아님.

원작과 한 픽셀 단위 비교는 이 보고서의 '완료' 항목에 포함되지 않는다.
