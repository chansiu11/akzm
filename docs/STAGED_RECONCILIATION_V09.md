# Java Edition 1.8.9 바닐라 비교·수정 반복 기록 — v0.9 로컬 작업본

2026-10-20. 비교 대상은 공식 Minecraft Java Edition 1.8.9 바닐라 **한 가지**이다. 아래 기능은 소스에서 독립 구현했으며 원본 Java 소스·원본 게임 에셋을 포함하지 않는다. **이 문서는 완성 검증서가 아니다.**

## 기준
- 입력: 바로 전 `akzm-stage4plus-local-preview.zip` (v0.8, Node.js 테스트 58개 통과).
- 수정본: `akzm-v0.9-reconciliation` (GitHub/Render 미적용).
- 방법: 기능 및 1.8.9 차이 식별 → 단위 및 회귀 테스트 → 코드를 수정 → 같은 테스트 재실행. 구현된 범위와 원작의 차이를 아래에 남긴다.

## A단계. 채굴, 드롭, 도구
| 발견한 차이 | 이번 수정 | 남은 차이 |
|---|---|---|
| 돌·잔디가 자신을 그대로 드롭 | 돌→조약돌, 잔디→흙 | 섬세한 손길·행운 효과 전체, 광물 경험치 |
| 석탄·다이아몬드 등 광석이 광석 블록을 직접 드롭 | 광물 아이템 별도 정의, 광석별 최소 곡괭이 등급 | 광물 분포 자체는 원작과 다름; 모든 채굴 도구 없음 |
| 블록 강도만으로 고정 파괴 시간 | 곡괭이 속도·채굴 가능 조건 반영 | 공중·수중·상태 효과·효율·피로·망치기 애니메이션 없음 |
| 곡괭이 종류/내구도 미구현 | 목·돌·철·금·다이아몬드 곡괭이 아이템, 사용 횟수와 파괴, 저장값 | 원작 장비 렌더링/내구도 UI/인챈트 미구현 |

테스트: 원작 스타일 기본 드롭·광석 등급·시간·등록 아이템·도구 손상·도구 이동과 저장값.

## B단계. 제작/인벤토리
| 발견한 차이 | 이번 수정 | 남은 차이 |
|---|---|---|
| 재료 수만 맞으면 제작 버튼만 누르는 방식 | 2×2/3×3 재료 배치와 모양 인식, 결과 수령 시 원자적 재료 소비 | 완전한 원작 제작법/마우스 드래그/Shift 제작/레시피 북 없는 원작 UI 표현 |
| 임시 잘못된 '돌→벽돌 블록' 시험 레시피 | 실제 모양이 있는 소수의 1.8.9 기본 제작법을 새 격자에 등록 | 기존 `src/crafting.js`에는 레거시 제작 API를 호환용으로 유지하되 잘못된 임시 레시피는 삭제. UI는 새 격자를 사용 |
| 도구도 일반 아이템처럼 중첩 가능 | 도구 1개, 눈덩이 16개 스택 한도 | 메타데이터·내구도·NBT 전체 구조 미완성 |
| 재료를 격자에 두고 닫을 때 유실 가능 | 인벤토리로 반환, 부족하면 바닥 아이템으로 배출 | 바닥 아이템 수량 상한·멀티 동기화 미완성 |

테스트: 재료 위치(형상) 검사·3×3 제한·완전한 슬롯일 때 복구·재료 반환·스택 상한.

## 확인 현황과 제한
- Node `npm test`: **74/74 통과**, 모든 수정된 JavaScript에 `node --check` 시행 예정.
- Chromium `page.set_content()`으로 데스크톱 1365×768과 모바일 390×844 메뉴 조작 검사: PASS.
- **인게임 GPU/WebGL 테스트: 실행 불가**. `http://127.0.0.1:8765/`에서 Chromium이 `net::ERR_BLOCKED_BY_ADMINISTRATOR`를 반환. 이전 환경과 같은 제한. 정상 플레이/메쉬/FP S를 확인했다고 주장하지 않는다.
- GitHub/Render 배포: **하지 않음**.

## 계속 다른 부분 — 전체 미완성 목록
1. Java 1.8.9 지형·바이옴·마을·구조물 시드 결과와 여전히 다름.
2. 블록 레지스트리 약 33종 수준. 원작의 전체 블록 상태, item/block model JSON 해석, 원본의 전체 게임 에셋은 미구현.
3. 하늘광·블록광 전파, 물/용암 흐름, 블록 중력과 업데이트 큐, 기후·하늘·그림자·파티클 대부분 미구현.
4. 제작법은 소수의 기본형만 구현. 화로/제련·양조·인챈트·모루·거래와 전체 아이템/장비/사운드도 차이 존재.
5. 실제 생물 1.8.9 클래스·애니메이션·AI·타깃 규칙, 주민·보스, 차원·포털·엔딩 미구현.
6. 서버 WebSocket 예제는 실게임과 미연결, Minecraft 1.8.9 바닐라 네트워크 호환 아님.
7. 명령어는 기존 8종 부분 지원만 유지. 마지막 단계의 모든 1.8.9 바닐라 명령어 및 인수별 Tab 완전 자동완성은 아직 미완료.
8. 엔티티/날씨/제작/블록 UI의 인게임 확인과 실제 원작과 병행 플레이 비교 **미수행**.
