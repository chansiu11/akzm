# 로드맵과 아키텍처

1. **0.1 코어**: 브라우저/WebGL(Three.js), 포인터 고정, WASD 시점, 물리/충돌, 블록 레이캐스트, 파괴·설치, 청크 기반 메쉬, 9슬롯 가방, 로컬 저장. [코드 작성; 브라우저 실조작 검증은 별도 필요]
2. **0.2 지형**: 여러 바이옴, 산·협곡, 동굴, 광물층, 명암·광원, 계단/반블록 등 비정육면체 충돌; 청크 비동기 재생성 및 최적화.
3. **0.3 서바이벌**: 36칸 인벤토리, 드롭/스택, 채굴 속도·도구/내구도, 2×2/3×3 제작법 데이터, 체력·배고픔·피해·사망.
4. **0.4 몬스터**: 독창적으로 제작한 몬스터 모델·애니메이션, AI FSM(배회 → 감지 → 추적 → 공격 → 귀환), 지형 경로 탐색, 드롭/스폰/전투.
5. **0.5 환경**: 낮밤 실제 스폰 및 조도 영향, 농사/물 흐름/화염, 바이옴, 구조물 및 월드 슬롯/백업/내보내기.
6. **0.6 멀티플레이**: `akzm`에 연결된 것으로 확인된 Render 서비스만 사용하여 서버 권한형 블록 수정·플레이어 이동, 서버 월드 저장, 접속 보안, 성능 테스트. 현재 Render 작업 대상은 사용자 워크스페이스 승인 전 변경하지 않음.

### 구분
- `src/terrain.js`: 순수 JS의 자연 지형 생성/편집 저장. Node 테스트 가능.
- `src/atlas.js`: 절차적 블록 색상 타일을 만드는 Canvas 2D 유틸.
- `src/main.js`: WebGL 메시, 플레이어 조작, HUD, 카메라, 포인터 락, 낮밤, 저장.
- 파일 콘텐츠는 CDN Three.js를 제외하고 순수 정적 호스팅; Render 서버 없어도 단일 플레이 가능.
