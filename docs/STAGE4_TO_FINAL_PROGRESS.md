# 단계별 구현·검증 기록 — 2026-10-20 (로컬 작업본, 미배포)

사용자 작업 방식: Minecraft **Java Edition 1.8.9 공식 바닐라만** 비교 대상으로 삼는다. 본 게임은 독립 코드/에셋 기반이며 원작 코드와 리소스를 재배포하지 않는다. 원작과 차이가 발견되면 **원작에 맞추기 위한 자동 수정은 하지 않고 차이점만 기록한다**. 오류 수정과 프로토타입 기능 추가는 작업 범위에 포함된다.

## 기반
- v0.7(3단계) ZIP 전체 소스에서 이어서 작성했다. 기존 블록 ID 0..28 보존, 세계 생성 형식 버전 3 유지, 브라우저 저장 키 유지.
- GitHub `chansiu11/akzm`과 Render 서비스는 **변경하지 않았다**.
- 이 빌드는 원작과 기능적으로 동등하지 않다. 개발본 이름에 final이 들어갈 수 있어도 '완성'을 의미하지 않는다.

## 기능 정확성 및 차이점 — 사용자에게 보고할 사항(원작에 맞춘 교정 전)
1. 같은 1.8.9 세계 시드를 사용해도 원작과 생성된 지형이 다르다(이전 3단계에서 확인한 차이, 유지).
2. 광원은 하늘/블록광별 계산이 아니고 씬 전체 조명이며, 구름과 비는 단순한 시각화이다.
3. 일부 신규 블록은 실제 1.8.9 형태/상태가 아닌 정육면체 또는 단순 모델이다. 특히 상자·화로·레버·램프의 모델과 전력 전달 범위가 다르다.
4. 시험 제작법 목록은 원작의 정식 2×2/3×3 재료 배치·개수·드롭 데이터를 그대로 따르지 않는다. `stone-bricks` 시험 레시피는 정식 레시피가 아니다.
5. 체력·허기·낙하·익사·전투·생물 AI는 원작의 틱·상태·길찾기·판정을 재현하지 않았다. `grazer`, `wanderer`, `shooter`는 게임 내 시험용 독립 생물이며 원작 생물과 1:1 대응하지 않는다.
6. 사운드가 합성 효과음이고, 원작 사운드를 자동으로 재생하지 않는다.
7. 브라우저 로컬스토리지 저장은 NBT/Anvil 형식이 아니며, 장기 플레이 시 용량 문제가 발생할 수 있다.
8. 서버 코드는 원작 Java 프로토콜과 호환되지 않고, 게임 브라우저 클라이언트와 연결되어 있지 않다.
9. 명령어 UI는 기존 v0.5의 부분 지원 상태이며, 모든 1.8.9 명령어와 전체 인수 Tab 자동완성은 미완료이다.
10. 실제 WebGL 3D 인게임의 FPS, 조작, 텍스처, 충돌, 몬스터 움직임은 지금 환경에서 직접 확인되지 않았다.

**이 차이들을 원작과 같도록 임의로 패치하지 않았다.** 독립 프로토타입의 기능 확장과 일반 버그 수정은 별도로 진행했다.

## 검증
- `npm test` Node.js 자동 테스트 **58개 통과**(기존 35개 + 추가 21개).
- `node --check src/*.js server/*.js`: 문법 검사 통과.
- Chromium DOM-only 메뉴/세계 생성/시드 입력: 데스크톱 1365×768, 모바일 390×844 검사 통과.
- `python3 -m http.server` 서버와 브라우저 `goto(http://127.0.0.1:8765/)`: 브라우저 접근 차단으로 **실제 WebGL 엔진 테스트 실패**. 따라서 인게임 검증/최종 원작 비교는 아직 완료하지 않았다.
- `server/`: 실제 서버 네트워크 통합 테스트는 `ws` 패키지 설치와 네트워크 연결 환경이 없어 수행하지 못했다. 순수 세션 로직만 테스트함.
